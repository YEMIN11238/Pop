AppleScript

打开 macOS 的“脚本编辑器”，通过应用名 Pop 调用本机已安装的应用。首次调用时，macOS 可能询问自动化权限。

翻译文字

tell application "Pop" to translate "Hello"

使用请求接口

tell application "Pop"
    request "{\"path\":\"translate\",\"body\":{\"action\":\"translateText\",\"text\":\"Hello\",\"target\":\"zh-Hans\"}}"
end tell

request 返回请求是否已受理。翻译结果随后显示在窗口，静默请求在原输入位置回填。

URL 调用

pop://translate?text=Hello&target=zh-Hans

可用文字动作包括 selectionTranslate、silentSelectionTranslate、silentInputBoxTranslate、snipTranslate、inputTranslate、pasteboardTranslate、showWindow 和 translateText。OCR 路径接受 ocrImage 及 imageBase64 图片数据。
