# 第一次使用 Pop

先用随包词典完成一次查词，再按需要开启跨应用取词和截图权限。无需先申请个人云 API Key。

[下载 DMG](https://yemin11238.github.io/Pop/download.html?format=dmg) · [下载 ZIP](https://yemin11238.github.io/Pop/download.html?format=zip) · [最新版本与校验文件](https://github.com/YEMIN11238/Pop/releases/latest) · [返回项目首页](../README.md)

## 1. 下载并安装

支持 **macOS 15 及以上**，同一个通用安装包适用于 Apple Silicon 和 Intel Mac。Windows、Linux、macOS 14 及更早版本不支持。

1. 下载 DMG，双击打开。
2. 把 **Pop.app 拖到 Applications（应用程序）**。等复制完成后，从访达的「应用程序」打开 Pop。
3. 安装后可以推出 DMG。若使用 ZIP，先解压，再把 Pop.app 移入「应用程序」。不需要安装 Xcode 或编译源码。

### 如果 macOS 拦截首次打开

当前发布包使用 ad hoc 签名，没有 Apple Developer ID 签名或公证。它与 App Store 安装方式不同，系统可能在首次打开时阻止运行。

1. 确认安装包来自 [YEMIN11238/Pop 的 Release](https://github.com/YEMIN11238/Pop/releases/latest)，并尝试打开 Pop 一次。
2. 打开「系统设置 → 隐私与安全性」，向下找到关于 Pop 的拦截提示，选择「仍要打开」。
3. 按 macOS 提示再次确认。需要密码或 Touch ID 时，由你本人完成。

不需要关闭 Gatekeeper、SIP 或整个系统安全保护。Release 中的 `SHA256SUMS.txt` 可用于检查文件是否完整：在终端运行 `shasum -a 256` 后接下载文件路径，将输出与同版校验文件比对。

## 2. 启动，先认识两个入口

打开 Pop 会显示设置页。这是配置快捷键、服务与权限的入口。关闭设置窗口不会退出 Pop；屏幕顶部的菜单栏图标仍可调用「输入翻译」「选图 OCR…」等操作。

- **设置页**：调整快捷键、翻译 / OCR 服务及其他偏好。
- **翻译 / OCR 窗口**：由快捷键或菜单项打开，用于输入内容、查看和复制结果。

默认服务包括「系统翻译」「简明英汉词典」和本机 OCR。可以直接开始，不必先添加付费服务。

## 3. 按一个快捷键，完成第一次查词

这条路径不需要录屏、辅助功能或个人云 API Key。

1. 按 **`⌥A`（Option + A）**，打开输入翻译窗口。
2. 输入 **`apple`**，按回车。
3. 找到 **「简明英汉词典」**卡片，查看词义。点击该卡片下方的复制按钮（两个重叠方框）。
4. 切到「文本编辑」的新文稿，按 `⌘V` 粘贴，确认词条内容已复制。

![输入 apple 后查看本地词典结果](assets/dictionary.png)

系统翻译也默认启用，因此第一次查询可能另外提示下载 Apple 语言包。词典的数据已经包含在安装包里，不依赖该下载；需要时可取消语言包下载，继续查看词典卡片。只想使用本地词典时，可到设置的「翻译 → 服务 → 文本翻译」停用系统翻译、保留词典并保存。

短词可能触发语言误判：本次实测中，自动识别把 `apple` 判为土耳其语。将原文明确设为「英语」、目标设为「中文简体」后，系统翻译返回「苹果」。这不影响 ECDICT 词典查询。

`⌥A` 无反应时，先点菜单栏 Pop 图标并选择「输入翻译」。在「翻译设置」检查快捷键是否与其他应用冲突；可以更换组合键。

## 4. 按需要授权

Pop 不要求先授予全部权限才能开始使用。下表只讨论录屏和辅助功能两项；macOS 的文件访问等其他提示仍以系统实际要求为准。

| 操作 | 录屏权限 | 辅助功能权限 |
| --- | --- | --- |
| 手动输入 / 粘贴文字、查本地词典、复制结果 | 不需要 | 不需要 |
| 从「选图 OCR…」选择图片，或识别已复制到剪贴板的图片 | 不需要 | 不需要 |
| 屏幕框选 OCR、截图翻译、原图翻译浮层 | 需要 | 不需要 |
| 在其他应用中划词取词 | 不需要 | 需要 |
| 把译文回填到其他应用的可编辑输入框，包括静默翻译 | 不需要 | 需要 |

**拒绝或暂不授权后**，仍可手动输入或粘贴待翻译文字，使用本地词典，选择本地图片做 OCR，并手动复制、粘贴结果。服务本身的语言包或 API 配置要求不变。

### 开启辅助功能，试一次划词翻译

1. 打开「系统设置 → 隐私与安全性」。在 macOS 15 / 26 中进入「辅助功能」；在本次实测的 macOS 27 中，这一页名为「设备控制和数据访问」。为 **Pop** 开启权限；若列表没有 Pop，用 `+` 选择「应用程序」中的 Pop.app。
2. 在文本编辑中新建文稿，输入 `Hello, world!` 并选中。
3. 按 **`⌥D`**，查看 Pop 中的原文与结果。首次用系统翻译时，按系统提示下载对应语言包。
4. 点击译文卡片的复制按钮，再回到文稿手动粘贴。若该输入框支持可验证的回填，也可以使用卡片的回填按钮。

回填依赖目标应用暴露的可编辑选区。密码框、只读内容和不支持的编辑器不适用；原选区或内容变化后，Pop 可能拒绝回填，可改为手动复制粘贴。

### 开启录屏，试一次截图 OCR

1. 打开「系统设置 → 隐私与安全性 → 录屏与系统录音」，为 **Pop** 开启权限。部分系统版本将此项称为「屏幕录制」。也可从 Pop 的「功能增强」页打开对应系统设置。
2. 若 macOS 提示「退出并重新打开」，按提示执行。
3. 在屏幕上显示一段测试文字，按 **`⌥⇧S`（Option + Shift + S）**，拖动框选文字区域。
4. 在 OCR 窗口核对识别结果，必要时编辑，再点击「复制」，切到文本编辑粘贴确认。默认开启自动复制 OCR 结果，可在「OCR 设置」更改。

截图 OCR 使用默认本机 Vision 服务，不需要个人云 API Key。图片不清晰、字号过小、复杂排版或受保护窗口可能影响识别；请先检查文字再使用。若暂不授予录屏权限，用菜单栏的 **「选图 OCR…」** 选择现有图片也可以识别。

## 5. 什么时候需要配置服务

- **系统翻译**：无需 API Key，但首次使用语言对时可能需要联网下载 Apple 语言包；支持的语言由 macOS 决定。macOS 15 可在普通窗口翻译。
- **Vision OCR 与随包词典**：默认本地服务，无需开通云账户。词典用于词库已有单词和词组，不能翻译整句。
- **云 API**：添加服务后填写对应地址、模型和密钥，再启用并保存。OpenAI 兼容服务、Gemini、Claude 等应选择匹配的协议；云端费用和额度由服务商决定。
- **本地模型**：先在本机安装、下载并启动 Ollama 或 LM Studio 的模型服务，再在 Pop 填写地址和模型名。Pop 不包含模型或模型运行器。使用远程地址时，查询会发送到该地址。

Apple 系统服务的**静默翻译和原图翻译浮层要求 macOS 26+**，并需先在普通翻译窗口下载对应语言包。普通截图翻译、Vision OCR 和词典在 macOS 15 可用。详见 [系统版本对照](../README.md#macos-15-与-macos-26-的差别) 和 [云服务说明](../CLOUD_SERVICES.txt)。

## 更新 Pop

1. 从 [最新 Release](https://github.com/YEMIN11238/Pop/releases/latest) 或产品页下载新版本 DMG / ZIP。
2. 通过菜单栏选择「退出 Pop」。
3. 将新 Pop.app 放入「应用程序」，替换旧版本，再打开。
4. 不要同时运行 DMG、下载目录和「应用程序」中的多个副本。更新无需删除 `~/Library/Application Support/Pop/`；该目录保存本机设置与历史。

当前签名方式可能使更新后的程序需要重新授权。若划词或截图失效，先确认运行的是「应用程序」中的 Pop，再检查系统的辅助功能 / 录屏开关。必要时从对应权限列表移除旧 Pop，重新添加当前 Pop.app，并按提示重新启动。只有相应功能失效时才需处理，手动输入和选图 OCR 可以继续使用。

发布页始终提供同版 DMG、ZIP 与 `SHA256SUMS.txt`。README 与产品页的下载入口会查找最新正式 Release，无需根据文档里的旧版本号猜文件名。
