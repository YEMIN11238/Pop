# 发布版演示与实测记录

记录日期：2026-10-15。本页区分实际完成的操作与尚未完成的验证；录制材料只应展示已经成功的流程。

## 环境与版本

- 测试对象为已发布的 **Pop 0.3.3（build 8）**，本轮没有修改应用程序或增加功能。
- 图形界面实测环境：**macOS 27.0.1（26A434），Apple Silicon（arm64）**。
- 使用现有 macOS 用户环境，已有 Apple 英中语言包；并非全新用户账号，也不能据此证明首次下载语言包或首次 Gatekeeper 放行的完整流程。
- 本轮 GUI 演示不使用个人云 API Key。外部云 API 和本地大模型未在本轮实测。

## 已完成的完整流程

| 场景 | 实际操作 | 结果 |
| --- | --- | --- |
| 随包词典 | 从「窗口」菜单打开「新翻译窗口」→ 输入 `apple` → 按回车 → 查看「简明英汉词典」词条 → 点击卡片复制 → 在 TextEdit（文本编辑）粘贴 | 真实 ECDICT 词条出现，复制与粘贴完整成功 |
| Apple 系统翻译 | 在输入窗口查询 `apple`，明确选择原文「英语」、目标「中文简体」 | 系统翻译实际返回「苹果」；使用已安装的语言包 |
| 本地图片 OCR | 在文件选择框选择自建中英测试图片 → 使用 Apple Vision 识别 → 复制结果 → 在 TextEdit 粘贴 | 识别与复制粘贴成功，输出内容如下 |

OCR 实际输出的文字为：

```text
Quick notes Read, copy, and keep moving. 图片里的文字，也可以复制。
```

这些内容为测试材料，不含个人文稿或账户信息。文件选择 OCR 与屏幕框选 OCR 是不同入口；这里的成功记录只覆盖文件选择入口。

## 实测发现的首次使用细节

- 在自动语言模式下，系统将单个词 `apple` 识别为土耳其语。显式选择英语 → 中文简体后翻译成功；ECDICT 查询不受该误判影响。
- macOS 27 的辅助功能授权页在本次环境中名为「设备控制和数据访问」；macOS 15 / 26 的教程入口仍为「辅助功能」。
- 当前发布版尚未匹配机器上的旧辅助功能与录屏授权记录。重新授权需要用户完成 macOS 的 Touch ID 验证；记录时仍在等待用户验证。

## 普通句子翻译补充

同一发布包通过菜单新建翻译窗口，手动输入 `Small steps make a big difference.`，明确选择英语到中文简体，Apple 系统翻译返回“小小的步骤会带来巨大的变化。”，点击复制后在文本编辑中粘贴一致。本图将词典卡片折叠，不代表跨应用划词触发已经实测。
