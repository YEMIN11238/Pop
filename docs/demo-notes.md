# 发布版演示与实测记录

更新日期：2026-10-16。本页区分实际完成的操作与尚未完成的验证；展示材料仅记录已成功的流程。

## 环境与版本

- 测试对象为已发布的 **Pop 0.3.3（build 8）**，本轮没有修改应用程序或增加功能。
- 图形界面实测环境：**macOS 27.0.1（26A434），Apple Silicon（arm64）**。
- 使用现有 macOS 用户环境，已有 Apple 英中语言包；并非全新用户账号，也不能据此证明首次下载语言包或首次 Gatekeeper 放行的完整流程。
- 本轮 GUI 演示不使用个人云 API Key。外部云 API 和本地大模型未在本轮实测。

## 已完成的完整流程

| 场景 | 实际操作 | 结果 |
| --- | --- | --- |
| 跨应用划词翻译 | 用户在 TextEdit（文本编辑）选中 `Small steps make a big difference.` 并实际按下 `⌥D` → Pop 取得原文并调用 Apple 系统翻译 → 点击译文复制 → 在 TextEdit 粘贴 | 原文一致，译文为“小小的步骤会带来巨大的变化。”，粘贴内容一致 |
| 屏幕框选 OCR | 点击 OCR 窗口顶部「截图 OCR」按钮 → 进入全屏框选界面，拖选 TextEdit 中的自建中英测试文字 → Apple Vision 识别 → 点击复制 → 在 TextEdit 粘贴 | 真实屏幕区域识别成功，复制粘贴一致；未通过 `⌥⇧S` 触发 |
| 随包词典 | 从「窗口」菜单打开「新翻译窗口」→ 输入 `apple` → 按回车 → 查看「简明英汉词典」词条 → 点击卡片复制 → 在 TextEdit（文本编辑）粘贴 | 真实 ECDICT 词条出现，复制与粘贴完整成功 |
| Apple 系统翻译 | 在输入窗口查询 `apple`，明确选择原文「英语」、目标「中文简体」 | 系统翻译实际返回「苹果」；使用已安装的语言包 |
| 手动输入句子翻译 | 从菜单新建翻译窗口 → 输入 `Small steps make a big difference.` → 明确选择英语到中文简体 → 点击译文复制 → 在 TextEdit 粘贴 | 系统翻译返回“小小的步骤会带来巨大的变化。”，粘贴内容一致 |
| 本地图片 OCR | 在文件选择框选择自建中英测试图片 → 使用 Apple Vision 识别 → 复制结果 → 在 TextEdit 粘贴 | 识别与复制粘贴成功；这是独立于屏幕框选的文件选择入口 |

## 演示素材如何制作

- README 与产品页展示划词翻译、屏幕框选 OCR、本地词典三个场景的真实画面，包含触发操作、结果出现与复制粘贴步骤。
- 动图是逐步截取真实操作画面后组合的**关键步骤回放，并非连续录屏**。划词场景由用户实际按 `⌥D`；屏幕 OCR 使用窗口按钮；词典使用窗口菜单。不能据此声称所有默认快捷键都已验证。
- 为采集画面，临时关闭了窗口失去焦点后隐藏的设置（`hideOnBlur`），采集结束后恢复。没有修改应用程序或翻译、识别结果。

## 实测发现的首次使用细节

- 在自动语言模式下，系统将单个词 `apple` 识别为土耳其语。显式选择英语 → 中文简体后翻译成功；ECDICT 查询不受该误判影响。
- macOS 27 的辅助功能授权页在本次环境中名为「设备控制和数据访问」；macOS 15 / 26 的教程入口仍为「辅助功能」。
- 机器原有的辅助功能与录屏开关虽然已打开，当前发布包最初仍显示未授权。用户完成系统认证后，在两项权限页分别移除旧 Pop 条目、重新添加当前发布包并开启权限；录屏按系统提示「退出并重新打开」。随后 Pop 的「功能增强」页显示两项权限均已开启，并完成了上述划词和屏幕框选实测。更新后的排查步骤见 [首次使用教程](first-use.md#更新-pop)。

- 译文回填、多屏行为、其他 macOS 版本或用户环境的 GUI、Intel Mac 的 GUI、首次 Gatekeeper 放行、首次下载语言包均未通过本轮演示验证。
- 自定义云 API 与本地模型（包括 Ollama、LM Studio）未在本轮实测。
- macOS 15 的 Apple Silicon / Intel 兼容性沿用 [v0.3.3 发布时的 CI 结果](https://github.com/YEMIN11238/Pop/actions/runs/38714077388)：两种架构启动和插件检查已通过。该结果不等同于本轮在 macOS 15 上完成了 GUI、授权或首次安装测试。

未覆盖的入口不作为本轮验证通过的结论。
