Pop 0.3.3 — macOS 翻译与 OCR

安装：把 Pop.app 拖入「应用程序」，然后从「应用程序」打开。
支持 macOS 15+，Apple 芯片和 Intel。无需安装开发工具或编译。
本版本未获 Apple Developer ID 签名与公证。首次联网下载的程序可能被系统拦截；确认来自官方项目后，可到系统设置 → 隐私与安全性选择「仍要打开」。
截图需录屏权限，跨应用划词/回填需辅助功能权限。免费系统翻译首次使用可能需下载语言包；OCR 与英汉词典可本地使用。
⌥D 划词翻译；⌥S 截图翻译；⌥A 输入翻译；⌥⇧S 截图OCR；⌥C 静默OCR。
第三方API服务需要自行填写URL、模型和密钥，服务费用由提供商决定。
